# 临期商品一单一销台账（电脑网页版）

浏览器打开即用的临期商品处置台账工具。一单一批、分类汇总、附表图片留痕，导出 Excel 主台账与每单一页 Word 存档。

## 一、它是干什么的

把《加油站非油业务管理办法》（陕高速延长发〔2024〕91号）第十七、十八、二十六条要求的临期处置过程，做成一条可追溯的证据链：

- 一单一批：每处理一批临期商品建一张单，不逐商品建单
- 分类汇总：只填品类、件数、金额，单品明细拍照上传附表
- 七组图片：明细附表、申请、审批、调价、销售、销单、审计
- 自动校验：临期金额按分类合计，占比超销售额 1% 自动标红
- 一键导出：Excel 主台账（图片嵌单元格）+ Word 存档（每单一页）


依赖全部本地化，断网也能用，不依赖任何 CDN。

## 三、本地直接运行（最简单）

双击 `index.html` 即可。但部分浏览器对 `file://` 下的 IndexedDB 有限制，推荐用本地服务器：

```bash
cd D:/非油临期管理
python3 -m http.server 8765 --bind 127.0.0.1
```

浏览器打开 `http://127.0.0.1:8765/index.html`

## 五、数据备份与迁移（重要）

数据存在浏览器 IndexedDB 里。以下情况会丢数据：清理浏览器数据、换电脑、换浏览器、用无痕模式。

**每次填报完成后，点右上角「备份 JSON」保存一份。** 换电脑时用「恢复 JSON」导入即可。

建议：每周五下班前备份一次，文件存到 WPS 云盘。

## 六、填报流程

1. 点「新建」，单号自动生成（LQ-年月-油站-序号）
2. 第 1 步：填油站/月份，批次号/盘点日期/总数；分类汇总填品类+件数+金额；上传明细附表图片
3. 第 2 步：填当月销售额、是否过期；填申请信息并上传申请截图；填 OA 单号、审批结果并上传审批截图
4. 第 3 步：填让利幅度、毛利损伤；上传调价截图；填销售情况并上传截图
5. 第 4 步：填销单日期、审计问题；上传销单截图；看自检清单全绿后点「确认销单」
6. 到「导出中心」导出 Excel 和 Word

图片上传支持：点击选择、拖拽、Ctrl+V 粘贴截图（电脑端最方便）。

## 七、制度口径（内置于页面「填报说明」）

- 第十七条(一)：达临期 2 个工作日内联系供应商退换；降价促销报计划经营科审批后执行
- 第十七条(三)/十八条(三)：管理原因过期按售价赔偿，站长 75%、非油主管 25%
- 第十八条(二)：每月报《商品报损申请表》，审批后报财务科
- 第二十六条(二)：未在保质期前 3 个月报告导致临期/过期超销售额 1%，站长约谈并扣当月 50% 非油提成
- 临期界定表 1：一年以上 45~30 天；半年以上不足一年 30~20 天；30 天以上不足半年 20~7 天；不足 30 天 5~1 天
